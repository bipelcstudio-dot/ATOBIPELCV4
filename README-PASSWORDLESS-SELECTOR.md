# BIPELC passwordless employee selector patch

این پکیج برای نسخه فعلی BIPELC OS ساخته شده است.

تغییرات:
- صفحه Login رمز و نام کاربری را حذف می‌کند.
- کارکنان فعال از D1 خوانده می‌شوند و به‌صورت کارت نمایش داده می‌شوند.
- انتخاب کارمند یک session عادی در جدول `sessions` ایجاد می‌کند؛ بنابراین ProtectedRoute و APIهای فعلی همچنان کار می‌کنند.
- Backend اصلی `src/index.js` دست‌نخورده می‌ماند و یک wrapper جدید در `src/selector-worker.js` قبل از آن قرار می‌گیرد.
- `wrangler.toml` به wrapper جدید اشاره می‌کند.
- صفحه انتخاب از ستون‌های واقعی Schema قدیمی شما (`id`, `username`, `full_name`, `role`, `position`, `status`, `permissions`) استفاده می‌کند.

فایل‌ها را در ریشه پروژه جایگزین کنید، سپس:

npm run build
npx wrangler deploy

نکته امنیتی:
این مدل «احراز هویت با رمز» نیست؛ عملاً انتخاب هویت/پروفایل است. هر کسی که به صفحه دسترسی داشته باشد می‌تواند هر کارمند فعال را انتخاب کند. برای یک سیستم داخلی/کیوسک مناسب است، ولی اگر سایت عمومی باشد باید بعداً یک عامل دوم برای جلوگیری از impersonation اضافه شود.
